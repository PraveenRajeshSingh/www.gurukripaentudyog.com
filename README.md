## 🔧 Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/www.gurukripaentudyog.com.git
   cd www.gurukripaentudyog.com
   ```

2. **Open in browser**:
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx http-server
     ```

3. **Access the site**:
   - Navigate to `http://localhost:8000` (or your server port)
